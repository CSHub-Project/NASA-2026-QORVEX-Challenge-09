# گزارش پیشرفت روز اول

تاریخ: ۵ نوامبر ۲۰۲۶

## تکمیل‌شده

- حساب Earthdata ایجاد و از طریق ایمیل رسمی NASA فعال شد.
- کلید FIRMS MAP_KEY ساخته، اعتبارسنجی و فقط در فایل محلی `.env` ذخیره شد؛ این فایل وارد Git نمی‌شود.
- سه محدوده پایلوت با مختصات دقیق در `configs/regions.json` ثبت شدند.
- pipeline دریافت MODIS Standard Processing و VIIRS S-NPP Standard Processing نوشته شد.
- محدودیت پنج‌روزه FIRMS API رعایت و retry نمایی برای خطاهای موقت شبکه اضافه شد.
- هر ۴۳۸ پارتیشن مورد انتظار سال ۲۰۱۹ دریافت شد: ۷۳ بازه برای هر ترکیبِ ۳ منطقه × ۲ حسگر.
- تبدیل `acq_date` و `acq_time` به datetime صریحِ UTC انجام شد؛ تعداد null برابر صفر است.
- ۵۳۴٬۷۰۳ مشاهده معتبر شامل MODIS، VIIRS، روز و شب پردازش شد.
- بازه زمانی داده از `2019-01-01 05:05 UTC` تا `2019-12-31 23:02 UTC` است.
- شش نمودار ماهانه count و FRP و دو خروجی Parquet تولید و کنترل بصری شدند.
- schema و معیارهای کمی موفقیت مستند شدند.
- تست‌های اولیه با موفقیت اجرا شدند.

## منتظر اقدام خارجی

- اتصال امن GitHub برای ایجاد remote repository و push.

## نتیجه علمی اولیه

- شمارش خام VIIRS در هر سه منطقه از MODIS بیشتر است؛ بنابراین تبدیل ساده و بدون تفکیک زمینه، سوگیری ایجاد می‌کند.
- اختلاف FRP تجمیعی دو حسگر به اندازه اختلاف count نیست؛ این مشاهده نشان می‌دهد count و FRP باید جداگانه harmonize شوند.
- تفاوت روز/شب به‌خصوص در VIIRS محسوس است؛ متغیر day/night باید در baseline و مدل نهایی حفظ شود.

جزئیات عددی و جدول کنترل کیفیت در `docs/day-1-results.fa.md` ثبت شده است.

## گام بعدی

1. ساخت baseline نسبت ثابت، جدا برای منطقه و روز/شب.
2. تعریف سلول‌های مکانی مشترک و پنجره زمانی هم‌مکان برای pair کردن مشاهدات.
3. تقسیم زمانی train/validation/test بدون نشت داده.
4. مقایسه مدل harmonization با baseline بر اساس bias، MAE، Spearman و bootstrap interval.
