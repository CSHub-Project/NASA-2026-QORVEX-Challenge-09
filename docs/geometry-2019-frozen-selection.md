# Geometry candidate selection before the 2023 test

The `--validation-only` command did not open the 2023 source. On 1,880 Western Iberia 2019 matched cell-passes, count WAPE was 0.739874 for the incumbent and 0.738860 for the geometry-aware candidate; MAE was 0.430543 and 0.429954 respectively. The preregistered rule therefore selects **geometry-aware** for the locked 2023 evaluation. The gain is only 0.001014 WAPE and does not establish a meaningful improvement by itself. The candidate is promoted only if all 2023 gates in `docs/2023-geometry-and-uncertainty-protocol.md` pass.
